# SO2 Spell List Reference

Compiled 2026-09-25 from RPGClassics' SO2 "Spell List" shrine (contributor: Edward Chang). Data
reorganized for this project's reference; descriptions paraphrased/condensed, not reproduced.

## Relevance to the save format

None established yet. Spells are gained by spellcasters (Rena, Celine, Leon, Noel, plus enemy-only
casts) automatically at fixed character levels — a different mechanic from the SP/Skill system this
project has mapped in the save file. Included for completeness/reference, not tied to any open
investigation item.
